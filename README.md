# Art_of_Motion
Art of Motion is a gesture-based system that enables users to control mouse operations and presentation slides using hand movements without physical input devices.
---

## 📌 Overview
Art of Motion is a gesture-based human–computer interaction system that allows users to control mouse operations and presentation slides using hand gestures. The system eliminates the need for traditional input devices like a mouse or keyboard by using computer vision techniques.

---

## 🚀 Features
- Gesture-based mouse control  
- Cursor movement using hand tracking  
- Left and right click using gestures  
- Slide navigation (next/previous)  
- Real-time gesture detection  

---

## 🛠️ Technologies Used
- Python  
- OpenCV  
- MediaPipe  
- PyAutoGUI  

---

## 🎯 Applications
- Smart classrooms (presentation control)  
- Touchless systems in public spaces  
- Assistive technology for disabled users  
- Interactive computer systems  

---

## ⭐ Advantages
- No physical contact required  
- Easy to use  
- Low cost system  
- Improves accessibility  
- Hygienic interaction
